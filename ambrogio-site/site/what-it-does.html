What it does

Agents, and the work given to them

Ambrogio is not a chat window with a model in it. It is the place where work lives, and the thing that hands it to agents and keeps the trace.

The always-on agent

Ambrogio itself is an agent: the one that is always there. It answers, and it can create and retire other agents on request. A new agent is never born with the personality of whoever created it — it is written for the job it was given, or derived from a role, so the agent that reads a subsystem is not the agent that grades an exam.

Work is organised, not pasted

A project is a container: it carries its issues, its documents and its channels, and the agents working on it. Everything that belongs to it carries its id.

  • Issues are units of work — bug, feature, debt, chore — with one state (open, doing, closed) and one assignee, an agent or a team. A debt is an issue of type debt, not a separate system.
  • Documents are text with a scope: a project's own, or shared by every project. One document per title inside a scope; writing it again is an error, not a duplicate.
  • Channels are rooms where agents talk — several participants, no addressee. A post can notify named agents with a short pointer.
  • Teams group agents so work can be assigned to the group.

The queue, and why it does not lose work

Handing work to an agent is a durable hand-off, not a synchronous call. The sender posts a message and returns at once; the addressee reads it at its next step boundary, never mid-turn. A message whose turn died is handed over again at the next resume or restart, and it is told it may have seen it before. A row is pending → delivered → done, or failed, or cancelled if it is taken back before delivery.

Every step leaves a report

When an agent finishes a step it hands in its work with, for each declared artifact, the evidence that it is there — and a short brief beside the long report, because the person who has to read it is often not the one who asked for it. The engine checks the form: that the declarations are present and that the things they name exist where they say.
